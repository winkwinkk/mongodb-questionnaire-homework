# 问卷系统说明

## 1. 项目简介

本项目实现了一个基于 Flask 和 MongoDB 的在线问卷系统，支持用户注册登录、问卷创建与管理、题目配置、条件跳转、在线填写、答案校验和结果统计。系统通过网页提供交互界面，由 Flask 处理业务请求，并使用 MongoDB 保存用户、问卷、回答及参与记录。

本项目主要用于实践 MongoDB 文档数据建模、后端接口开发和问卷业务逻辑实现。

## 2. 技术环境

| 技术 | 用途 |
|---|---|
| Python | 编写后端业务逻辑 |
| Flask | 提供网页路由和 REST API |
| MongoDB | 存储用户、问卷、题目、回答及参与记录 |
| PyMongo | 实现 Python 与 MongoDB 的交互 |
| HTML、CSS、JavaScript | 实现网页界面与前后端交互 |

项目在 Windows 环境下开发，具体依赖见根目录中的 `requirements.txt`。

## 3. 功能模块

| 功能模块 | 主要功能 |
|---|---|
| 用户认证 | 用户注册、登录、退出及当前用户信息查询 |
| 问卷管理 | 创建问卷、修改草稿、发布问卷、设置截止时间和关闭问卷 |
| 题目管理 | 添加、编辑和删除单选、多选、文本及数字题 |
| 答案校验与条件跳转 | 检查答案合法性，并根据预设规则确定后续题目 |
| 问卷填写与提交 | 逐题填写、跳过可选题、提交回答及控制重复填写 |
| 结果统计 | 查看问卷提交数量、选项分布、文本答案和数字统计 |

## 5. 安装与运行

### 5.1 首次安装与启动

先安装Python及MongoDB，并启动MongoDB服务。在PowerShell进入解压后的项目根目录（含app.py），使用项目内虚拟环境：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.ps1 -PythonPath '.\.venv\Scripts\python.exe'
```

脚本不会代替安装依赖或启动MongoDB；它检查解释器、准备会话密钥、初始化集合和索引，再启动Flask。之后只需执行启动命令，端口占用可加-Port 5001。脚本默认解释器位于项目上一级.venv，新环境需像上例显式指定路径。完整配置及脚本受限时的替代方式见 [README](../README.md)。

### 5.2 访问与权限

浏览器访问 http://127.0.0.1:5000 。注册登录后创建草稿、添加题目与规则，再发布并复制/survey/<id>填写链接。填写者同样必须登录，完成后正式提交；创建者查看统计。密码保存为哈希，登录采用签名Session Cookie。列表、管理和统计按ownerId隔离，页面模板能打开不等于API授予访问权限。

草稿可改结构，发布后题目及匿名、重复设置锁定；published可设置截止或关闭，closed无重开接口。匿名不取消登录，只在回答中省略账号字段，数据库参与记录仍可关联身份。

### 5.3 当前范围

默认仅监听本机，跨设备访问需另行配置。尚无问卷删除、导出、发布后版本编辑、自动保存答题草稿或大规模压测；部分非法ID异常与时间后缀尚未统一。统计由Python汇总，提交恢复是可恢复协议而非跨集合事务。详细限制见 [关键逻辑](key-logic.md)。
