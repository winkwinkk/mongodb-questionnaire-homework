### 3.1 注册与登录

1. POST `/api/register`，输入以下 JSON，预期并实际断言 HTTP 201。
2. POST `/api/login`，输入相同 JSON，预期并实际断言 HTTP 200。
3. 后续请求复用同一测试客户端，保留登录 Cookie。

```json
{"username":"owner","password":"password123"}
```

### 3.2 标识与问卷约定

S 表示创建接口返回的 `survey.id`；Q1～Q4 表示添加题目接口返回的真实 `question.id`。它们在实际请求中均为 ObjectId 字符串，不是字面字符串 S、Q1 等。后文带这些符号的路径和 JSON 是便于阅读的模板，复现时必须替换为返回值。

主流程问卷显式设置 `anonymousAllowed=true`、`allowMultipleResponses=true`，用于连续保存两份样本并检查统计。默认禁止重复的场景另由 TC07 验证。

| 题号 | 题型 | 标题与输入限制 |
| --- | --- | --- |
| Q1 | single_choice | 是否跳转；required=true；yes/是、no/否 |
| Q2 | text | 可跳过的必答题；required 使用默认 true |
| Q3 | number | 年龄；required=true；min=0、max=120、integerOnly=true |
| Q4 | multiple_choice | 必答多选；required=true；a/A、b/B；数量采用默认配置 |

### TC09 同账号并发与提交恢复

| 场景 | 测试步骤与输入 | 预期输出 | 实际输出 | 结果 |
| --- | --- | --- | --- | --- |
| 同账号并发 | 六线程发送12次合法答案 {F1:yes,F3:18,F5:并发} | 同一资格仅保存一份回答 | 状态仅201或409，至少一次201；成功响应使用同一 responseId；回答和参与记录各1条 | 通过 |
